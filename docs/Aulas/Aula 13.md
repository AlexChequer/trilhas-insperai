# Aula 13 — Reinforcement Learning + Fechamento

**Status: ⬜ pendente** (0/2) · slug `aula-13` · **Marco: lança o Projeto 2**

## Objetivo

Entender o **terceiro paradigma** de aprendizado, fechar o semestre e lançar o Projeto 2.

## Blocos (roteiro)

Agente/ambiente/recompensa (por que não é supervisionado; recompensa atrasada) →
exploração × explotação (epsilon-greedy; a analogia do restaurante) → política e
**Q-learning** (tabela Q não escala → rede neural entra, fecha o arco) → **RLHF** (o
LLM cru prevê texto plausível, não útil; conecta A12 → por que o ChatGPT responde
assim) → **lançamento do Projeto 2** (tema livre; grupos; exemplos de escopo bom e um
grande demais) → fechamento (retrospectiva do arco; deploy como o que falta; passagem
pra membro).
