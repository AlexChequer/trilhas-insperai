# Aula 08 — Claude Code

**Status: ⬜ pendente** · slug `aula-08` · **Aula prática — sem visualização interativa**

## Objetivo

Ganhar a ferramenta e a **postura de revisor** junto. A regra da aula: **você pode
delegar a escrita, não pode delegar a decisão** (arquitetura, hiperparâmetro,
diagnóstico continuam sendo do trainee).

## Blocos (roteiro)

Prompt engineering (contexto antes do pedido; ser específico; dar exemplo) → janela
de contexto (o modelo só vê o que está na janela; sessões curtas) → fluxo de dev
agêntico (delegar tarefa × pedir trecho; spec antes de prompt) → **o momento mais
importante:** pedir um modelo com **erro sutil embutido** (vazamento do teste, métrica
errada) e mostrar a ferramenta entregando com confiança total → construção ao vivo
(parar em cada decisão e perguntar à turma).

## Material (não é viz interativa)

- Exemplos lado a lado de **prompt ruim × prompt bom** para o mesmo objetivo.
- O **caso do erro sutil**, documentado no repo (código + explicação do que estava errado).
- **Checklist de revisão** para código de ML gerado por IA.
